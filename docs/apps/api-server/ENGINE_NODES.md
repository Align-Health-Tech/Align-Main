## Graph nodes

LangGraph nodes under `engine/nodes/` (plus Devise+QG **phases** owned by a
node — not separate topology entries). Each may `interrupt()` with a
`NextStep`.


| Name                           | Kind                               | Shape                                                                                                                         | Design decisions (why)                                                                                                                                                                                                                                                                                                                                                                                                                                                          | Prompts / smoke                                                                                                                 |
| ------------------------------ | ---------------------------------- | ----------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| `presenting_complaint`         | Graph node                         | (1) Free-text gate → (2) classify → clarify until `ready: true` → LOCALISED / NOT_LOCALISED                                   | Classifier does **not** emit clarify text (3-agent rule: Devise+QG owns clarify). At `ready: true`, `chief_complaint` ← `chiefComplaintSummary` (`source: "ai_summary"`); raw words stay in `messages`, not a separate DB column.                                                                                                                                                                                                                                               | `classifier/presenting_complaint.md` · smokes: `smoke_presenting_complaint_classifier/`, `smoke_presenting_complaint_clarify/`  |
| `presenting_complaint_clarify` | Devise+QG phase (owned by PC node) | `devise_then_generate` when PC `ready: false`                                                                                 | Empty registry pool — invent topics from routing gap. Region options 1:1 `majorRegion` (Face/Arm/Leg/Torso); no “arm or leg” groups. `en_prompt`/`en_label` only if `session_language != "en"`.                                                                                                                                                                                                                                                                                 | `devise_and_prioritise/presenting_complaint_clarify.md`, `question_generation/presenting_complaint_clarify.md`                  |
| `localised_detail`             | Graph node                         | After PC routes LOCALISED → (1) SVG body-diagram tap → (2) severity + adaptive duration → priority | **Round 1** gate = empty `body_structures`; resume `{"region_id"}` → `map_body_diagram`. Prefill SVG via `resolve_prefill_candidates`. **Round 2:** deterministic `loc_severity` (0–10) + QG phase `duration` (`devise=False`, adaptive chips + Other) → `SessionState.duration`. Severity also stamped onto `body_structures[0]`. No region/laterality MCQs — SVG owns site. | Helpers: `catalogues/body_diagram/` · QG: `question_generation/duration.md` · smoke: `smoke_duration/` · tests: `test_body_diagram.py`              |
| `non_localised_detail`         | Graph node                         | (1) Six-bucket categoriser + clarify until `non_localised_category` set → (2) severity / functional + adaptive duration → priority | Bucket `category` ≠ LOCALISED/NOT_LOCALISED; apply via `prompt_name="non_localised_categoriser"` only. `**run_classifier` nulls PC-only fields**. **Max 3 clarify rounds.** Stage 2: deterministic score chips + QG `duration` → `SessionState.duration`. | `classifier/non_localised_categoriser.md` · `question_generation/duration.md` · smokes: `smoke_duration/`, `smoke_non_localised_categoriser/` · tests: `test_nl_clarify_rounds.py`      |
| `non_localised_clarify`        | Devise+QG phase (owned by NL node) | When categoriser `ready: false`                                                                                               | Options exactly `Yes` / `No` / `I don't know` (validator-enforced); no `"Other"`. Feature presence/absence only. `en_`* only if not English.                                                                                                                                                                                                                                                                                                                                    | `devise_and_prioritise/non_localised_clarify.md`, `question_generation/non_localised_clarify.md`                                |
| `priority_questions`           | Graph node (Devise+QG)             | Rank registry priority targets → batch questions → redflag                                                                    | **Prefill-and-confirm** via `known_collect_values`. Apply: `medication` → `encounter_medication`; `pregnancy` → bool; `character` / `comorbidities` → narrative lists; `onset_circumstance` → singular narrative; `allergy` → `intake_facts` `ALLERGY` (negative options such as `"No allergies"` produce no fact). Shared chip/Other parsing + Pattern E translate. Comorbidities: `"None of these"`, never `"Other"`. Pregnancy sex-filtered. | `devise_and_prioritise/priority_questions.md`, `question_generation/priority_questions.md` · smoke: `smoke_priority_questions/` |
| `redflag_screening`            | Graph node (Devise+QG)             | After priority → optional                                                                                                     | Pilot `infer_lilly_red_flags` style (soft register, presentation-anchored observables) without Mild/Moderate/Severe or `synthesisLogic`. Full `REDFLAG_TARGETS` pool every time (**not** locality-filtered). Devise ≤3 topics (`relevance ≥ 0.65`). QG: **1–3 flat `yes_no` per topic** (default 2; never OR-bundle); same `collect_target_id` may repeat. Cap `max_questions=9`. `is_red_flag=True` stamped in code. | `devise_and_prioritise/redflag_screening.md`, `question_generation/redflag_screening.md` · smoke: `smoke_redflag_screening/`    |
| `optional_questions`           | Graph node (Devise+QG)             | After redflag → ice                                                                                                           | Skippable (`required: false`; empty Devise/QG → skip). Cap 4. Apply intake_facts: `past_history` / `family_history` / `social_history`. Encounter: `self_management`, `weight_change`, `exacerbating_factors`, `mitigating_factors`. Shared `selections.py` + Pattern E translate. | `devise_and_prioritise/optional_questions.md`, `question_generation/optional_questions.md` · smoke: `smoke_optional_and_ice/`   |
| `ice`                          | Graph node (QG only)               | After optional → review                                                                                                       | `devise_then_generate(..., devise=False)` — no Devise; empty topics/eligible. Exactly three `multi_choice` targets in order: `ice_idea`, `ice_concern`, `ice_expectation` — chips + mandatory `Other`. Mapper joins selections into one NarrativeField each. Facade validates QG output.                                                                                                                                                                                         | `question_generation/ice.md` · smoke: `smoke_optional_and_ice/`                                                                 |
| `review`                       | Graph node (single agent)          | After ice → complete                                                                                                          | **Silent** — no patient interrupt / NextStep. Calls `run_nurse_review_summary_agent` → `encounter_summary`. Fixed scan order: red flags → chief complaint + severity + duration (+ character) → allergy (when collected) → ≤2 extras (no meds/ICE dump). Survey (if any) is router-level after complete.                                                                                                              | `nurse_review/summary.md` · smoke: `smoke_nurse_review/`                                                                        |
| `complete`                     | Graph terminal                     | After review                                                                                                                  | Marks session complete; patient-facing survey (if configured) is outside the graph.                                                                                                                                                                                                                                                                                                                                                                                            | —                                                                                                                               |


**NL force-commit detail:** primary = `non_localised_category_lean` (best-fit `category` on `ready: false`); fallback = `SYSTEMIC`.

## Helpers (not nodes)

Shared utilities nodes call. Not in the graph topology.


| Name                                                                       | Where                                       | Role                                             | Design decisions (why)                                                                                                                                                                                                                                                                                                                                                     |
| -------------------------------------------------------------------------- | ------------------------------------------- | ------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `map_ai_result`                                                          | `engine/session_state_mappers/map_ai_result.py` | Dispatch AI results → state updates           | Counterpart to `map_patient_answers`. Routes `ClassifierResult` → `ai/classifier_result.py`, `ReviewSummaryResult` → `ai/nurse_review.py`. Import via `from engine.session_state_mappers import map_ai_result`.                                                                                                                                                                                                           |
| `map_classifier_result`                                                  | `engine/session_state_mappers/ai/`            | Map ready `ClassifierResult` → state updates     | Branches on `prompt_name`: PC → `presentation_category` + optional ai_summary / anatomy / supplement; NL categoriser → `non_localised_category` **only**. Prevents bucket labels corrupting `presentation_category`.                                                                                                                                                                                                              |
| `map_nurse_review`                                                       | `engine/session_state_mappers/ai/`            | Map `ReviewSummaryResult` → `encounter_summary`  | Thin mapper used by `review` node via `map_ai_result`.                                                                                                                                                                                                                                                                                                                                                                              |
| `map_patient_answers`                                                    | `engine/session_state_mappers/map_patient_answers.py` | Map resume answers → state updates        | Root dispatcher + `patient/` phase mappers; shared `selections.py` / `shared.py` stay at package root. Import via `from engine.session_state_mappers import map_patient_answers`.                                                                                                                                                                                                                                            |
| `build_agent_context`                                                      | `engine/agent_bridge.py`                    | `SessionState` → LLM context dict                | Projection only — omit interrupt plumbing. Conversation via `conversation_from_state` separately. Includes NL rounds/lean, `known_collect_values` (QG prefill), plus full clinical fields for nurse-review synthesis. CI patches `engine.agent_bridge`. Unused keys are ignored by other agents.                          |
| `get_eligible_targets` / `targets_for_session_phase`                       | `intelligence/registry.py`  | Sex + locality filter on priority/optional pools | `targets_for_session_phase` maps graph phase → filtered targets (shared by Devise pool + QG eligible). Already-known status is via `known_collect_values` on agent context, not these functions. Pilot-parity: e.g. `onset_circumstance` LOCALISED-only; optional `past_history` LOCALISED-only; `family_history` / `weight_change` / `social_history` NOT_LOCALISED-only. |
| `body_diagram_catalogue` (`resolve_prefill_candidates` / `resolve_coding`) | `catalogues/body_diagram/`     | Classifier sites → SVG prefill / `CodedField`    | Two tables: `PREFILL_MAPPINGS` (region_id may repeat across views) vs `REGION_CODINGS` (unique id → coding). `surface="unknown"` → first body_part+side catalogue hit, not a hardcoded surface.                                                                                                                                                                            |
| `duration` (QG phase)                                                         | `intelligence/prompts/question_generation/duration.md` | Adaptive duration question in loc/nl detail | `devise_then_generate("duration", devise=False)`. Maps to `SessionState.duration`. Validator: exactly 1 `single_choice` with `collect_target_id="duration"` + Other. Smoke: `smoke_duration/`. |
| `narrative_dump_free_text` / `narrative_dump_option`                       | `engine/session_state_mappers/narrative.py` | Pattern E: patient free text → `NarrativeField`  | When `session_language != "en"`, calls `engine.agent_bridge.translate_to_english` → set `en_text`. Option chips skip translation. Sole mapper→AI import (via agent_bridge).                                                                                                                                           |
